How the Safety Test Works

Banker's Algorithm
1 CALCULATE NEED = MAX − ALLOCATION
2 FIND A PROCESS WITH NEED ≤ WORK
3 RELEASE ITS ALLOCATION INTO WORK
A safe sequence proves that every process can eventually complete under the current resource assumptions. An unsafe state means the OS cannot guarantee such a sequence.
